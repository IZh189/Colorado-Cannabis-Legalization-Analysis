# Colorado Cannabis Impact Study

This project examines the economic and public safety effects of recreational cannabis legalization in Colorado using the Synthetic Control Method (SCM).

## Overview

The study evaluates whether cannabis legalization led to measurable changes in key economic and public safety indicators by comparing Colorado to a synthetic control constructed from similar U.S. states.

The Synthetic Control Method is used to estimate the causal impact of legalization while accounting for pre-existing trends and state-specific characteristics.

## Research Question

What were the economic and public safety impacts of recreational cannabis legalization in Colorado?

## Methodology

- Synthetic Control Method (SCM)
- Comparative policy analysis
- Counterfactual estimation
- Statistical analysis in R and Python

## Technologies

- R
- Python
- Synth package
- Data Analysis
- Statistical Modeling
- Policy Evaluation



## Results

The project estimates the causal effects of recreational cannabis legalization on selected economic and public safety indicators by comparing observed outcomes in Colorado to those of a statistically constructed synthetic control.
